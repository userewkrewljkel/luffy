# LUFFY 3.16 — preview candidate

This candidate is built separately from the public 3.14 beta release. It has **not** undergone manual audio-device and UI validation.

## Changes

- A small, dedicated circular reset arrow beside True Peak resets only the TP maximum. The global Reset button is unchanged.
- After TP-only reset, the display reads **—** until a new True Peak of at least −70 dBTP has been detected. This avoids a meaningless near-silence value such as −83.7 appearing immediately after reset. Very quiet signals below this threshold intentionally do not repopulate the TP field. True Peak processing, warning crossings, and peak recording continue independently.
- During internal WAV playback, the TP reset affects the playback meter only, not the paused live session.
- Integrated LUFS value is green within ±1 LU of the selected target, red above target +1 LU, and otherwise uses the standard text color. Short-term LUFS is not color-coded. True Peak value turns red if the active TP warning threshold is exceeded.
- Added on-demand **Tools & diagnostics → Save desktop screenshot…** (PNG, all monitors); no continuously running screenshot buffer.
- Ambient Mode is not included. The existing red TP screen-edge warning remains.
- Updated version header, window names, executable, and build script to 3.16.

## Required manual checks before promoting to a public release

1. Click TP-only reset during live audio, during silence, and while paused. Confirm **—** until a new non-silent level is measured.
2. Check I/S LUFS, elapsed time, WAV recording, warning events, and playback state remain unchanged after TP-only reset.
3. During built-in WAV playback, reset TP and ensure the stored live session remains untouched.
4. Confirm dedicated TP reset remains clickable without overlapping adjacent text across supported font sizes, settings, and DPI scaling.
5. Save a screenshot on a multi-monitor system; verify correct file and no persistent CPU or memory cost.
6. Verify color thresholds at −23 LUFS (or selected target), TP warning limit, and when warnings are disabled.
7. Compare sustained and short True Peak measurements against v3.14 and Youlean using known audio samples.
8. Test global reset, source switching, capture, WAV player, screen-edge warning, and single-instance startup.

Keep 3.14 available for rollback. A successful GitHub Actions build does not verify measurement accuracy.
