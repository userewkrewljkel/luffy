# LUFFY v3.14 Beta

A free, compact loudness meter for Windows x64.

## What's included

- Integrated and Short-term LUFS, True Peak, stereo peak bars and custom loudness targets.
- Visual True Peak warnings around your screens.
- Optional Peak Capture saves WAV clips around peaks on your selected Windows audio source. Capture is off by default.
- Built-in Peak Capture Player with waveform preview, an approximate trigger marker, seeking, output selection and listening gain.
- Playback mode measures the original WAV before listening gain. Your live session pauses during built-in playback and resumes afterward with its history preserved.
- Manage saved captures and move recognized capture files to the Windows Recycle Bin after confirmation.

## Download and run

Download `LUFFY-v3.14.exe` and run it on 64-bit Windows. It is a self-contained build; a separate .NET installation is not required. `SHA256SUMS.txt` contains the executable's checksum.

This executable is built by GitHub Actions from the source commit attached to this release. It is unsigned, so Windows may show an unknown-publisher warning.

## Beta limitations

Automated compilation verifies that the source builds; it does not certify audio accuracy. This release has not completed the full manual device, capture and playback test checklist. Keep your previous build available and report problems through GitHub Issues or contact@andreasbusk.com.

Direct ASIO capture is not supported. A DAW using ASIO may need an interface loopback input. Built-in playback pauses live monitoring, so live audio during that preview is excluded from measurement. Trigger markers are approximate. Preview gain may clip what you hear but never changes the saved WAV.
