# LUFFY 3.17 — Windows preview candidate

**This is an unreleased test candidate, based on the 3.16 preview branch.** Public version 3.14 remains untouched.

## New behavior

- **Automatic True Peak screenshots (optional):** Settings → True Peak → Screenshot Capture. Disabled by default; captures the entire Windows virtual desktop (all connected monitors) after a real TP crossing, even if the red screen-edge warning is disabled. No continuous screenshots, video, pre-peak image buffer or background polling. Only one PNG can be in progress. Default cooldown: 10 seconds (adjustable 5–300 seconds).
- Screenshot storage: `Pictures/LUFFY/Peak Screenshots`. Automatically generated screenshots use `LUFFY_TP_yyyy-MM-dd_HH-mm-ss_fff_<8 hex>.png`, so the bulk cleanup only targets this app's named files.
- **Two independent Recycle Bin actions** in Settings → True Peak → Manage saved recordings:
  - Move all Peak Capture WAV recordings (including matching `.wav.txt` metadata) to Recycle Bin.
  - Move all LUFFY True Peak PNG screenshots to Recycle Bin.
- Both operations ask for confirmation, only touch the relevant configured directory, disable their own recording option before the deletion, and **never permanently delete as a fallback**. Screenshots and WAV recordings never delete one another or unrelated user files.
- Removed the incorrect manual 'Save desktop screenshot…' menu item. True Peak screenshots now trigger automatically when enabled.
- Simplified right-click menu to Settings, Pause/Resume, Reset measurement and Exit; all other settings remain in the Settings window.
- Updated executable, app window titles and single-instance lock to v3.17.

## Manual verification before release

1. With auto screenshots disabled, cross TP threshold; no PNG is produced.
2. Enable screenshots, cross TP threshold, and confirm one PNG is saved in Pictures/LUFFY/Peak Screenshots. Compare its timestamp to the peak event. Confirm it captures all connected displays, including the expected DAW/FMOD state.
3. Cross repeatedly: verify minimum interval and that the screenshot is not taken continuously during a held peak. Recheck when the red screen-edge warning is disabled.
4. Confirm the **Test True Peak warning** button does not save a screenshot; paused measurement and built-in WAV playback must not produce new screenshots.
5. Use **Move all Peak screenshots to Recycle Bin…** after making several captures. Cancel confirmation (nothing changes), then confirm. Check only matching screenshots were moved; unrelated PNG and WAV files remain.
6. With a screenshot write in progress, confirm the cleanup waits for it to finish before moving files.
7. Verify **Move all Peak Capture recordings to Recycle Bin…** moves WAV + matching metadata and does not touch screenshots. Test with an empty folder and inaccessible Recycle Bin.
8. Confirm both recording switches are independent and existing settings persist through upgrade.
9. Check new TP-only reset from 3.16, LUFS/TP numerical colors, playback/preview, overlay, global reset and single instance.
10. Compare true-peak readings against a reference meter (Youlean) before trusting new builds in production.

**Known limitation:** An image is captured after LUFFY has observed a threshold crossing, not before it. The desktop may already have changed by the time capture occurs. PNGs may include private information displayed on any connected monitor.
