# LUFFY — public website and downloads

This repository is for the **public LUFFY website and executable distribution**, not the Windows application's source code.

- Website: https://userewkrewljkel.github.io/luffy/ (after the public-repository migration)
- Windows beta: https://github.com/userewkrewljkel/luffy/releases
- Support: contact@andreasbusk.com

The site is built with HTML, CSS, SVG and vanilla JavaScript.

The Windows **C# application source is maintained in a separate private repository**. Automatic GitHub "Source code" archives of this repository include only the public website files; they are not application source code.

Before moving the existing download, ensure the matching release EXE and SHA-256 checksum are uploaded to the public release. Update the download links together; do not leave an EXE linked from a private repository.

For usage information, see [Getting started](docs/getting-started.md).
For beta reports, use the [issue template](.github/ISSUE_TEMPLATE/bug_report.yml). Do not post private screenshots or audio in public issues.
