What it measures

LUFS
Integrated and Short-term loudness, with targets you can adjust.
True Peak
A peak reading and an optional screen-edge warning when your chosen limit is exceeded.
Stereo peaks
Small L/R bars show the input channel peaks beside the loudness readings.
Audio source
Select a supported Windows input or output device. Direct ASIO capture isn't supported; a DAW may need an interface with loopback.

Peak Capture and playback

If a peak needs a closer look, Peak Capture can save a WAV clip around it. Turn it on in Settings → True Peak. It's off by default.

The player lets you browse saved clips, seek in the waveform and choose an output. The trigger marker is approximate.

LUFFY measures the original WAV before listening gain. During built-in playback, your live measurement pauses. It resumes afterward with its history preserved; live audio during the preview is excluded.

A few notes

Windows shows an unknown publisher warning

This beta is unsigned. The EXE is built from the source on GitHub; download it from the release page linked above. A SHA-256 checksum is provided alongside it.

Where are recordings saved?

Peak Capture saves WAV files locally, by default in Music/LUFFY/Peak Captures. You can choose another folder in Settings. Preview gain doesn't change the saved audio.

Can I use it for unattended monitoring?

Built-in playback pauses live monitoring, so don't review clips during a measurement you need to keep continuous. This is a beta; check important readings against a trusted reference.

What if something goes wrong?

Keep your previous build so you can go back to it. Open an issue on GitHub or email me with the version, audio device and what happened.
